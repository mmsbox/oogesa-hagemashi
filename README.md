# 全力で励ますボタン

押すたびに褒め言葉がどんどん大げさになり、10回目で宇宙規模になる、全力で励ましてくるクソアプリです。

疲れたとき、ちょっと病んだとき、とりあえず押してください。

## 遊び方

1. 「はげまして」ボタンを押す
2. 押すたびに褒め言葉が大きくなり、画面・キャラ・声もエスカレートしていく
3. 10回目で宇宙に到達。その先には……
4. 褒め言葉を集めて図鑑を埋め、実績の解除を目指す

## 機能

### 段階ごとのエスカレート

- 1〜3回目：落ち着いたクリーム色の画面
- 4〜7回目：パステルの丸が浮かび、キャラが丸くなって喜び始める
- 8〜10回目：濃紺の宇宙モード。星がきらめき、キャラがギザギザになってブルブル震える
- 10回目：後光が回り、紙吹雪が舞う

### 声で褒める

ブラウザの読み上げ機能で、褒め言葉を実際にしゃべります。段階によって声の高さや速さが変わり、10回目だけ低くゆっくりした声になります。

### ランダム褒め・SSR

- 段階ごとに4種類の褒め言葉からランダムで1つ
- 3%の確率で金色に光る「SSR褒め」が出現

### 褒め図鑑

出た褒め言葉が記録され、図鑑で一覧できます。まだ出ていない言葉は「？？？」で表示されます。

### 実績

全11種類。一部は隠し実績です。

| 実績                     | 条件                         |
| ------------------------ | ---------------------------- |
| はじめての褒め           | 1回褒められる                |
| 宇宙に到達               | 10回褒められる               |
| 賢者タイム               | 宇宙のその先へ               |
| 在庫切れ                 | 褒めを使い切る               |
| 輪廻転生                 | 在庫切れのあと、もう一度     |
| 用法・用量を守れなかった | 連打する                     |
| 放置プレイ               | 10秒なにもしない             |
| 選ばれし者               | SSRを引く                    |
| 褒められマスター         | 通常の褒め言葉をすべて集める |
| ？？？                   | ？？？                       |
| ？？？                   | ？？？                       |

### その他のネタ

- ボタンの文言も「はげまして」から「宇宙をよこせ」までエスカレート
- 宇宙のあとは褒めの語彙が尽きて、燃え尽きる
- 連打すると注意される
- 放置すると追い褒めされる

## 動かし方

ビルドや環境構築は不要です。

1. このリポジトリをクローン、またはダウンロード
2. `index.html` をブラウザで開く

音声読み上げを使うため、音量をオンにして遊んでください。iPhoneでは消音モードだと声が出ません。

## ファイル構成

```
.
├── index.html   # 画面の骨組み
├── style.css    # 見た目・段階ごとの演出
└── script.js    # 褒め・声・実績・図鑑のロジック
```

## 使用技術

- HTML / CSS / JavaScript（フレームワークなし）
- Web Speech API（`speechSynthesis`）：褒め言葉の読み上げ
- localStorage：実績と図鑑の保存
- [canvas-confetti](https://github.com/catdad/canvas-confetti)：紙吹雪
- [Google Fonts（Zen Maru Gothic）](https://fonts.google.com/specimen/Zen+Maru+Gothic)：フォント

### 見た目の仕組み

JavaScript は `body` の `data-level` 属性に「今何段目か」を書き込むだけで、色・形・背景の切り替えはすべて CSS が担当しています。色は CSS 変数にまとめてあり、段階ごとに変数を上書きすることで画面全体が切り替わります。

## データのリセット

実績と図鑑はブラウザに保存されます。最初からやり直したい場合は、開発者ツールのコンソールで以下を実行してからリロードしてください。

```js
localStorage.removeItem("homeAchievements");
localStorage.removeItem("homeZukan");
```
